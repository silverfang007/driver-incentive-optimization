# Driver Incentive Optimization

## From Marketplace Data to a Targeted Business Decision

### Portfolio Case Study — Amit Shah

---

## 1. Executive Summary

### The question

Marketplace businesses often use incentives to increase supply.

The challenge is that a blanket incentive can be inefficient.

Some drivers may already be highly active and would have participated without an incentive, while other drivers may be much more responsive to targeted interventions.

The business question for this analysis was:

> **Can we identify driver segments where incentives are more likely to create incremental activity?**

The analysis compares three approaches:

- **Control** — no incentive
- **Broad** — incentive distributed broadly
- **Targeted** — incentive focused on selected driver segments

The analysis uses synthetic marketplace data to demonstrate the methodology.

---

# 2. Why This Matters

An incentive program should not be evaluated simply by asking:

> "Did activity increase?"

A more useful question is:

> **"How much additional activity did the incentive create relative to what would have happened anyway?"**

This distinction matters because incentives have a cost.

Consider two drivers:

### Driver A

Already completes a high number of trips.

Giving this driver an incentive may increase activity slightly, but much of the activity may have happened anyway.

### Driver B

Has moderate activity but responds strongly when given an incentive.

A similar incentive may generate substantially more incremental activity from Driver B.

Therefore, the objective becomes:

> **Allocate incentive spend toward behavioral segments where the expected incremental return is highest.**
