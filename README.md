# Driver Incentive Optimization

## Turning Marketplace Data into Decision-Ready Insights

**Portfolio Case Study — Amit Shah**

> How can a marketplace reduce incentive waste while maintaining incremental driver activity?

---

## Executive Summary

Marketplace incentive programs can increase supply, but broad incentives may spend money on participants who would have remained active anyway.

This project explores a simple business question:

**Can behavioral segmentation help identify where incentive spend is most likely to generate incremental activity?**

The analysis compares:

- **Control** — no incentive
- **Broad Incentive** — incentive distributed broadly
- **Targeted Incentive** — incentive focused on selected behavioral segments
